# GitHub Summary

Product Data Science case study on **314,953 sampled e-commerce events**. The project defines session funnel and retention metrics, builds a leakage-safe conversion model with chronological validation (**0.819 ROC-AUC; 9.5% precision while capturing 54.0% of purchases in the top-risk 10%**), audits segment and nonlinear model behavior with SHAP, and converts observational findings into a powered cart-recovery experiment plan.
