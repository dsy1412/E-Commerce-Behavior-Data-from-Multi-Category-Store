# Resume Bullets

- Built a reproducible product analytics pipeline over **314,953 e-commerce events** from **31,287 users**, preserving user journeys through deterministic sampling and defining DAU, session funnel, conversion, segmentation, and cohort-retention metrics.
- Developed a leakage-safe session conversion model using first-5-minute behavior and chronological validation; compared baseline, logistic regression, and LightGBM models, reaching **0.819 ROC-AUC** and **0.136 average precision (7.7x the historical-rate baseline)**.
- Diagnosed a **6.04% view-to-cart rate** and segment-level conversion differences with SHAP and root-cause analysis, then designed a powered user-randomized cart-recovery experiment with explicit metrics and guardrails.

All figures and claims above are generated from the current local run. Re-run the pipeline after changing the data sample before using the numbers externally.
